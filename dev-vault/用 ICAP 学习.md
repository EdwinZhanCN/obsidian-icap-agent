这是一篇真正的笔记，不是说明书。它讲的是一个学习理论；读它的时候，你会亲手用到这个插件的全部四种交互——它们都发生在文档里，就在你读到的地方。读完后它就是你的第一篇学习笔记：可以继续写、保留，或者删掉。

## 四种投入方式

ICAP 框架（Chi & Wylie, 2014）把学习时的投入分成四种外显的模式，并认为从被动到互动，理解依次加深：

- **被动（Passive）**：接收信息——阅读、听讲，但不做额外的处理。
- **主动（Active）**：对材料动手——划线、摘抄、重读、暂停回放。
- **建构（Constructive）**：产生材料里没有的东西——用自己的话解释、举一个新例子、自我解释、比较两个概念。
- **互动（Interactive）**：与一个会回应的伙伴共同建构——互相追问、质疑，在对方的回应上继续推进。

互动的关键不是“轮流说话”，而是双方的贡献互相建立在一起。所以一个只会给答案的助手，会把你推回被动；好的导师做的是 scaffolding，而不是讲解。

## 试一试

### ① 解释：在原地读懂一个词

在上一段里**双击** *scaffolding* 选中它，稍等片刻，选区旁会出现一个小标记——点 **explain**。解释会出现在那一段的正下方，左侧有一道墨线：它属于这篇笔记，而不是另一个窗口。

读完可以继续要 **deeper**、**example**、**plainer**；有用就 **keep in note**，它会变成一个普通的 callout；否则 **dismiss**，笔记不会留下任何改动。

### ② 互动：回答一个问题

选一个答案并提交。之后由 Agent 接手：它会就你的选择给出反馈——如果选错了，它不会直接公布答案，而是追问一个问题让你自己找到——然后再问一两个问题。整个过程都留在这个块里。

```icpa-ask
id: guide-quiz
kind: quiz
authored: yes
topic: ICAP 的四种模式
---
小林读完一章后合上书，用自己的话写下这一章的主要观点，又举了一个书里没有的例子。按 ICAP，这属于哪种模式？
- [ ] 被动——只是在读书
- [ ] 主动——在整理书里已有的内容
- [ ] 建构——产生了材料之外的解释和例子
- [ ] 互动——写作就是在和作者对话
```

### ③ 回忆与反馈：用自己的话说

开始写的时候，笔记的其余部分会变模糊——这是刻意的：从记忆里提取，比重读更能巩固理解（按 Esc 取消模糊）。提交后，Agent 会指出遗漏或误解，并追问一个问题，而不是替你改写。最后选 **write it up**：你认可的那个版本会留在笔记里，下面附上反馈。

```icpa-ask
id: guide-recall
kind: recall
authored: yes
topic: 建构与互动的区别
---
不往回看，用自己的话解释：**建构**和**互动**有什么区别？为什么说互动不只是“轮流说话”？
```

### ④ 活动：看 Agent 做了什么

点 **开始**，Agent 会在库里为 ICAP 写一篇概念笔记，并**提议**把这篇指南里第一次出现的“ICAP 框架”改成链接——修改以差异的形式出现在块里，只有你点 apply 之后才会写入。

```icpa-ask
id: guide-agent
kind: agent
authored: yes
topic: ICAP 框架
start: 开始
---
为 **ICAP 框架** 写一篇独立的概念笔记，并把它和这篇笔记连起来。
```

任务进行时，右下角状态栏会有一个小圆点。点开它就是 **Activity**：每项任务的状态（进行中、等你回答、完成、停止），以及它最后新建和修改了哪些笔记。
