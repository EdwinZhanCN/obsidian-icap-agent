The guide note **Learning with ICAP** is a short text about the ICAP framework. While you read it, you use each interaction of the plugin once. When you finish, the note is your first study note.

If the guide note is not open, open the command palette and run **Open the guide**. The command also makes the note again if you deleted it.

## 1. Get an explanation

1. In the section "Four ways of engaging", double-click the word *scaffolding*.
2. Next to the selection, select **explain**.

The explanation shows below the paragraph, with a line of ink in the margin.

3. To change the explanation, select **deeper**, **example** or **plainer**.
4. Do one of these:
   - To keep the explanation, select **keep in note**. The plugin writes it into the note as a callout.
   - To remove it, select **dismiss**. The note does not change.

## 2. Answer a question

1. In the question block, select an answer.
2. Select **submit**.

The agent replies to your answer. If the answer is wrong, the agent does not give the correct answer. It asks a question that helps you find it.

## 3. Explain from memory

1. In the recall block, start to write your answer.

The rest of the note becomes blurred, so you answer from memory. To remove the blur, press Esc.

2. Submit your answer.

The agent tells you what is missing or wrong, and asks a follow-up question. It does not write your answer for you.

3. When you finish, select **write it up**. Your final answer and the feedback stay in the note.

## 4. Let the agent make a note

1. In the block "Write a separate concept note on the ICAP framework", select **start**.

The agent writes a concept note in your vault. It also proposes a change to the guide note: a link to the new note. The block shows the change as a diff.

2. Read the diff. To write the change, select **apply change**.

While the agent works, a dot shows at the right of the status bar. To see the activity, select the dot.

## 5. Ask for anything

1. Put the cursor on an empty line.
2. Open the command palette and run **Ask the agent here**.
3. Type a request, then press <kbd>⌘</kbd> <kbd>↵</kbd> (on Windows and Linux, <kbd>Ctrl</kbd> <kbd>↵</kbd>).

In a request:

- Type `[[` or `@` to add a link to a file. The agent uses the files that you link.
- Type `/` at the start for a command, for example `/model` to use a different model in this block only.

4. When you finish, select **keep a record**. The conversation becomes plain Markdown in the note.
