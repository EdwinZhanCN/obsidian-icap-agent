1. In Obsidian, open **Settings → Community plugins**.
2. If restricted mode is on, select **Turn on community plugins**.
3. Select **Browse**.
4. Search for **ICAP Learning Agent**.
5. Select **Install**, then select **Enable**.

The plugin opens a guide note, **Learning with ICAP**. Keep it open. You use it in [Your first lesson](/start/first-lesson/).

## Install by hand

Use this procedure only if you cannot use the community plugins browser.

1. Download `main.js`, `manifest.json` and `styles.css` from the latest [release](https://github.com/EdwinZhanCN/obsidian-icap-agent/releases).
2. Put the three files in `<your vault>/.obsidian/plugins/icap-agent/`.
3. In Obsidian, open **Settings → Community plugins**, then enable **ICAP Learning Agent**.

## If you used ICPA

ICPA (`icpa-agent`) is the earlier name of this plugin. On its first start, ICAP copies the settings of ICPA. After that, remove ICPA.
