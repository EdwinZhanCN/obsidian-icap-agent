---
title: Getting started
description: Install ICAP Learning Agent and connect a model.
---

1. In Obsidian, open **Settings → Community plugins → Browse**.
2. Find *ICAP Learning Agent*. Install it, then enable it.
3. Open **Settings → ICAP Learning Agent**.
4. Log in to a model provider, or add an API key.
5. Open the guide note that the plugin made.
6. Select a passage, then ask for an explanation.
