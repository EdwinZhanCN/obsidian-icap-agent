## Get an explanation

1. Select a word or a passage.
2. Next to the selection, select **explain**.

The explanation shows below the paragraph. While the agent writes, a line of ink grows in the margin.

:::note
You can also open the command palette and run **Explain selection in context**. On a phone, this command is in the toolbar.
:::

## Change the explanation

After the explanation, select one of these. Each adds a part to the same explanation.

| Select | To get |
|---|---|
| **deeper** | more detail and the reason behind it |
| **example** | an example |
| **plainer** | the same idea in simpler words |
| **compare…** | a comparison with a concept that you type |

## Keep or remove the explanation

- To keep it, select **keep in note**. The plugin writes the explanation into the note as a `gloss` callout, with the parts that you added.
- To remove it, select **dismiss**. The note does not change.

An explanation that you do not keep is lost when the plugin reloads.

## What the agent uses

The agent explains from what you know. It reads the note around the selection, your background in the settings, the notes that you wrote yourself, and the recalls and checks that you did. If you kept a **plainer** or **deeper** part before, the agent takes it into account the next time.
