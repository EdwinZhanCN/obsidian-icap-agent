Agent 按你需要的深浅来解释，不按固定的新手或专家水平。它从你的笔记中找出你懂什么。插件没有隐藏的个人档案：所有证据都是 Markdown，你可以读、改、删。

## 为什么深浅很重要

对新手有帮助的解释，可能拖慢专家。学习研究把这叫做「专长逆转效应」（expertise reversal effect）。所以，Agent 解释之前必须对你有所了解。它也不能声称知道得比实际更多。插件的协议要求 Agent 只根据它真正读过的证据来适应你的水平。如果它把一篇笔记当作证据，它必须说出是哪一篇。

## 证据，从弱到强

| 证据 | 说明什么 | 强度 |
|---|---|---|
| 库中的资料，例如书和剪藏 | 你接触过这个主题 | 弱 |
| 设置中的 **你的背景** | 你认为自己懂什么 | 弱 |
| 保留的解释中 **说浅一点** 和 **更深入** 的部分 | 什么深浅适合你 | 弱，但会累积 |
| 你自己写的笔记 | 你可能懂这个主题的一部分 | 中 |
| 保留的回忆和检查：你的话、结果和日期 | 你真正懂什么 | 强 |

保留的测验介于这些强度之间：它逐题说明你能认出什么。最近的 ✓ 比很久以前的 ≈ 更有分量。

## 谁写了什么

只有 Agent 能分清你写的和它自己写的，证据才有用。如果它把自己的笔记当成你的笔记，它会看到并不存在的理解。所以，插件标记 Agent 写的每样东西：

- Agent 新建的笔记，属性中有 `generated-by: icap-agent`。
- 保留的解释是 `gloss` callout。
- 保留的请求中，回复在 `request` callout 中。其中只有 **请求:** 开头的行是你写的。
- 反馈在 `feedback` 或 `practice` callout 中。你的话在 callout 外面，紧挨在它上方。

Agent 不把自己写的任何文字当作你懂什么的证据。任务笔记也不是证据。

## 每条记录都带日期和结果

保留的回忆或检查，callout 标题中有日期和一个标记：✓ 成立，≈ 部分成立，? 再想想。callout 上方的注释写着同样的日期和结果，还有主题。保留的测验统计各题的标记。所以，不需要插件的数据，每条记录也带着自己的日期，Agent 能看出证据有多旧。

## 每个任务 Agent 得到什么

对每个任务，插件从笔记中给 Agent 一份上下文：

- 笔记的路径、标题和属性，
- 焦点上方的各级标题，
- 焦点周围的段落、所在的一节，以及焦点周围的一部分笔记，
- 笔记中的链接，
- 设置中的 **你的背景**。

只在需要时，Agent 才去找更多内容。例如，解释一个术语之前，它可以查看这个术语的反向链接，并查找你自己写的相关笔记。插件不扫描整个库。它没有向量数据库，也没有知识图谱。

## 轻量的判断

解释总是先给出。Agent 不在解释之前测试你。如果没有证据，而新手和专家需要的解释差别很大，Agent 按笔记本身的水平来写。然后它为另一种水平加一行短句，例如「如果你已经懂 X：……」。

Agent 每次只针对一个概念或一篇笔记判断你的水平。没有全局的水平，也没有跟着你的分数。

## 插件中的 ICAP 框架

ICAP 框架把学习者做的事分成四种方式。越深的方式通常带来越好的学习。插件让每种方式都容易，但不让错误的做法变容易：

| 方式 | 插件让这件事容易 | 插件不让这件事容易 |
|---|---|---|
| 被动 | 不离开段落就弄懂一个难懂的术语 | 用 Agent 的文字代替你的阅读 |
| 主动 | 决定什么留在笔记中 | 自动保存所有内容 |
| 建构 | 不看原文，用自己的话写 | 让 Agent 改写你的回答 |
| 互动 | 回答一个追问，然后修改 | 变成没有目的的闲聊 |

方式指你做什么，不指某个控件叫什么。选一个选项不是互动的学习。只有你和 Agent 都对内容进行推理、互相回应并修改，对话才是互动的。

所以，对错误的回答，Agent 给出提示或一个问题，不直接给出正确答案。回忆、检查和测验都只是提供给你的机会。不做这些，你也总能阅读和提问。
