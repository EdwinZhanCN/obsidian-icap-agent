## 获取解释

1. 选中一个词或一段文字。
2. 在选区旁，选择 **解释**。

解释显示在段落下面。Agent 书写时，页边会长出一条笔迹线。

:::note
你也可以打开命令面板，运行 **在上下文中解释选中内容**。在手机上，这个命令在工具栏中。
:::

## 改变解释

解释写完后，选择下面的一项。每一项都在同一个解释中加一部分。

| 选择 | 得到 |
|---|---|
| **更深入** | 更多细节和背后的原因 |
| **举个例子** | 一个例子 |
| **说浅一点** | 用更简单的话说同一个意思 |
| **对比…** | 与你输入的概念做对比 |

## 保留或去掉解释

- 要保留，选择 **留在笔记里**。插件把解释连同你加的部分，作为 `gloss` callout 写进笔记。
- 要去掉，选择 **丢弃**。笔记不会改变。

你没有保留的解释，在插件重新加载时会消失。

## Agent 依据什么

Agent 从你已经知道的内容出发解释。它读选区周围的笔记、设置中你的背景、你自己写的笔记，以及你做过的回忆和检查。如果你以前保留过 **说浅一点** 或 **更深入** 的部分，Agent 下次会考虑到。
