有时，一个滑块比一段文字教得更多。Agent 可以在回复或新笔记中放一个交互式图示：带滑块的图表、可以逐步查看的过程，或先预测结果再查看的练习。你可以从图示中向 Agent 追问。

<RequestDemo client:only="svelte" lang="zh" kind="visuals" />

## 获取图示

1. 打开一个请求块：运行 **在这里向 Agent 提问**。
2. 请求一个你想动手试的内容，例如「让我看看升力怎样随迎角变化。」
3. 选择 **发送**。

Agent 书写时，图示显示为 *正在画图示…*。回复完整后，图示才显示。

Agent 也可以在它新建的笔记中放图示。它不会往已有的笔记里加图示。

## 选择 Agent 什么时候画图示

在 **设置 → ICAP Learning Agent → 笔记中** 设置 **交互式图示**：

| 选项 | Agent 画图示的时候 |
|---|---|
| **有帮助时** | 你可以通过动手来学的时候：改变一个值、逐步查看一个过程，或预测一个结果。这是默认值。 |
| **只在我要求时** | 只在你的请求要求图示时。 |
| **不用** | 从不。 |

图示不代替解释、反馈、问题或对笔记的修改。

## 从图示中提问

图示可以有一个按钮，把问题发给 Agent。选择这个按钮：

- 如果图示在请求块中，问题就是这个块中的追问。
- 如果图示在笔记中，插件在图示下面打开一个新的请求块，并发送这个问题。

图示也可以打开库中的一篇笔记，例如通过一个按钮。

只有在你选择了图示之后，它才能发送问题或打开笔记。它不能在打开时发送请求，也不能之后自己发送。所以没有你的操作，图示不会消耗 token。

## 图示能做什么

图示在沙箱中运行。它读不到你的笔记、Obsidian 和你的文件，也不能访问网络。

图示使用你的主题颜色，主题改变时它也跟着改变。如果它的脚本出错，图示下面会有一行字告诉你。

## 在笔记中

图示是笔记中的一个 `icap-ui` 代码块。它包含 HTML 以及它的样式和脚本：

````md
```icap-ui
<label>迎角 <input id="a" type="range" min="0" max="20"></label>
<button onclick="icap.ask('为什么超过 15° 后升力会下降？')">提问</button>
```
````

它是普通的 Markdown。如果你移除插件，笔记中显示的是代码。插件不保存图示的状态：再次打开笔记时，图示从头开始。
