Agent 可以为你写新的学习笔记。每篇笔记有一段核心思想、关键细节、需要时的一个例子，以及指回你的笔记和相关概念的链接。插件直接新建笔记。不经你决定，它不会修改你已有的笔记。

下面，Agent 整理一篇笔记的关键概念。它先问你写哪些概念，再新建笔记，并在笔记中提出一处链接。

## 新建概念笔记

1. 在笔记中选中这个概念。
2. 打开命令面板，运行 **用选中内容新建概念笔记**。也可以右键选中的内容，选择 **新建概念笔记**。

Agent 为这个概念写一篇笔记。它按你的笔记中的用法解释这个概念。

## 整理一篇笔记的关键概念

1. 打开这篇笔记。
2. 打开命令面板，运行 **把本笔记的关键概念整理成笔记**。
3. Agent 列出一些概念。选择你要写成笔记的概念。
4. 选择 **提交**。

Agent 为你选择的每个概念新建一篇笔记。如果你一个也不选，它不新建笔记。

## 写对比笔记

1. 可选：选中第一个概念。
2. 打开命令面板，运行 **写一篇对比笔记…**。
3. 在 **对比概念** 窗口中，如果 **这个** 是空的，就输入第一个概念。
4. 在 **和** 中输入第二个概念。
5. 选择 **写对比笔记**。

这篇笔记说明每个概念的用途、重要的区别、两者的共同点，以及什么时候用哪一个。

## 把交互写成笔记

回忆、检查或测验完成后，在块中选择 **写成笔记**。

Agent 用这段交互写一篇笔记。笔记中有你最终的说法、你纠正的误解和最重要的反馈。Agent 不改动你的原话。

## 图表、白板和 Base

如果图或表比文字更能说明内容，Agent 也会用 Obsidian 自己的格式。它在请求的回复和新笔记中用这些格式。它不在解释、反馈和提问中用这些格式。

| 格式 | Agent 写什么 | 什么时候用 |
|---|---|---|
| 图表 | 笔记中的 `mermaid` 代码块 | 流程、循环、原因、状态，或按顺序发生的事件 |
| 白板（Canvas） | 一个新的 `.canvas` 文件 | 你要自己整理和扩展的概念图 |
| Base | 一个 `base` 代码块，或一个新的 `.base` 文件 | 按属性列出笔记的表格或卡片 |

- 图表用你的主题的颜色和字体。图中的节点可以链接到一篇笔记。
- 插件在写入文件前检查每个白板和 Base。如果文件在 Obsidian 中打不开，Agent 收到原因并改正文件。
- 要修改已有的白板或 Base，Agent 提出修改。你应用修改，或让文件保持原样。

要让 Agent 做一个，在请求块中写下请求，例如「把这篇笔记里的概念做成一个白板」。

## Agent 提问或提出修改时

工作中，Agent 可能在笔记中问你一个问题，例如包括哪些概念。见[回答 Agent 的提问](/zh-cn/learn/agent-questions/)。

如果你的笔记提到了一个现在有了自己笔记的概念，Agent 可以提出加一个链接。块中显示这处修改：

- 要加上链接，选择 **应用修改**。
- 要让笔记保持不变，选择 **保持笔记原样**。

Agent 完成后，块中显示结果。选择 **留在笔记里**，把结果保留为一个 `note` callout；或选择 **清除**，移除这个块。

## 笔记放在哪里

- Agent 为每篇新笔记选择文件夹：按库中 `AGENTS.md` 的规则，或放在相关笔记旁边。要把所有新笔记放在同一个文件夹，设置 **新笔记的位置**（**设置 → ICAP Learning Agent → 文件**）。
- 打开 **标记 Agent 新建的笔记** 时，每篇新笔记都有属性 `generated-by: icap-agent`。Agent 用这个属性区分它写的笔记和你写的笔记。它不把自己写的笔记当作你理解了的证据。
- 任务完成后，一条通知告诉你 Agent 新建了哪些笔记。[活动](/zh-cn/learn/activity/)记录每个任务，并链接到这些笔记。
