请求块是笔记中的一个位置，你在这里用自己的话给 Agent 写请求。Agent 可以读你的笔记和资料，新建笔记，并对你的笔记提出修改。块中显示回复和 Agent 改动的文件。留下什么由你决定。

## 打开请求块

1. 把光标放在要放块的位置。要把一段文字交给 Agent，就选中它。
2. 打开命令面板，运行 **在这里向 Agent 提问**。也可以在笔记中右键，选择 **在这里向 Agent 提问**。

块显示在光标所在段落的下面。如果你选中了文字，Agent 会和请求一起收到选中的内容。在手机上，这个命令在工具栏中。

要关闭空的块，选择 **暂不**。

## 写请求

1. 写下请求。
2. 选择 **发送**，或按 ⌘ Enter（Windows 和 Linux 上按 Ctrl Enter）。

Agent 工作时，块中显示它在做什么，例如 *思考中…* 或 *书写中…*。要停止 Agent，选择 **停止**。要重新开始，选择 **继续**。如果任务失败了，选择 **重试**。

Agent 收到的是你写的原话，还有笔记的名称、块上方的标题和选中的内容。

## 链接文件

要告诉 Agent 用哪些笔记或资料，就在请求中链接它们。

1. 输入 `[[` 或 `@`。
2. 输入文件名的一部分。
3. 在列表中选择文件。

插件写入的是普通链接，例如 `[[伯努利原理]]`。`@` 是输入同一个链接的简便方法。Agent 收到的是每个文件的路径，不是文件内容。它用自己的工具读需要的部分。

## 使用命令

以 `/` 开头的请求是命令。输入 `/` 可以看到命令列表。

| 命令 | 作用 |
|---|---|
| `/model` | 只在这个块中换用另一个模型。`/model default` 恢复为设置中的模型。不带名称时，显示这个块的模型。 |
| `/thinking` | 只为这个块设置思考强度：`off`、`minimal`、`low`、`medium`、`high` 或 `xhigh`。`/thinking default` 恢复为设置中的值。 |
| `/compact` | 为 Agent 压缩前面的轮次。笔记不变。只在桌面端可用。 |

这三个命令在块中用一行短字回答。它们不属于对话，记录中也不包括它们。

使用 **你的 Pi 配置 + ICAP** 时（**设置 → ICAP Learning Agent → 高级 → Agent 配置**），列表中还有你自己的 Pi skills、提示模板和扩展命令。使用 **仅 ICAP（隔离）** 时，列表中只有上面三个命令。命令只在请求块中有效。在回忆、检查或测验中，开头的 `/` 只是普通文字。

## 审查建议的修改

Agent 不会自己修改已有的笔记。它在块中提出修改：

- 标题显示 **建议修改** 和笔记的名称。
- Agent 删除的行前面有 −，添加的行前面有 +。

然后做下面一项：

- 要把修改写入笔记，选择 **应用修改**。
- 要让笔记保持不变，选择 **保持笔记原样**。

Agent 随后继续工作。你决定后，这处修改折叠成一行，例如 *已采纳 · +2 −0*。选择这一行可以再次查看修改。

:::note
使用 **你的 Pi 配置 + ICAP** 时，Agent 还有你自己的 Pi 工具。这些工具可以不经审查直接修改文件。块和[活动](/zh-cn/learn/activity/)会列出 Agent 新建、修改或删除的每个文件。
:::

## 追问

Agent 完成后，回复下面显示一行 **继续追问…**。

1. 写下追问。这里也可以用 `[[`、`@` 和 `/`。
2. 选择 **发送**。

对话在同一个块中继续。前面的每一轮折叠成一行。选择一行可以再次打开它。

Agent 对这段对话的了解，就是块中显示的内容。在桌面端，如果打开了 **记住请求的上下文**（**设置 → ICAP Learning Agent → 高级**），只要之前的会话与块一致，Agent 就继续这个会话。在手机上，每次追问都把整段对话重新发给模型。

## 查看花费

回复下面有一行字，显示这段对话的 token、提示词从缓存读取的比例和价格，例如 *7.7k tokens · 缓存 42% · ≈$0.012*。≈ 表示按模型的公开价目估算。如果不知道价格，这一行显示 *花费未知*。

## 保留记录

Agent 完成后，选择 **保留记录**。插件用一个 `request` callout 替换这个块：

- 你的每个请求，写在 **请求:** 后面
- Agent 的回复
- **文件:** 后面，Agent 新建或修改的每个文件的链接

记录中的链接是普通链接，所以关系图谱会显示这个请求用了哪些笔记。

要移除这个块、什么也不留，选择 **清除**。Agent 新建或修改的文件保持不变。

如果这个请求成了一个任务（Agent 用了工具、改动了文件、问了你问题，或对话超过一轮），插件还会用一篇任务笔记记录它。见[活动](/zh-cn/learn/activity/)。
