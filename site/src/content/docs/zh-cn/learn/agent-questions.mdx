工作中，Agent 可能会问你一个问题：用哪个定义、包括哪些笔记，或某处修改是否正确。问题显示在笔记中的一个块里。Agent 会等你回答。

<AskDemo client:only="svelte" lang="zh" kind="agent" />

## 找到问题

有问题在等你时：

- 状态栏显示 **轮到你了**。
- 如果那篇笔记没有打开，会有一条通知告诉你问题在哪篇笔记中。选择通知即可打开那篇笔记。
- 在活动中，这个任务显示空心圈，状态是 **等你回应**。

在手机上，从侧边功能区打开活动。

## 回答

1. 选择一个答案，或写下答案。
2. 提交。

Agent 用你的回答继续工作。

## 停止任务

要停止任务，选择块中的 **停止**。以后要继续，选择 **继续**。
