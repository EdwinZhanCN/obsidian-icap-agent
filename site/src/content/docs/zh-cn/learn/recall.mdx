复述，就是不看原文，用自己的话解释一节内容。它比重读原文更能帮你记住。Agent 针对你写的内容回应，不替你写答案。

## 开始复述

1. 把光标放在这一节中。
2. 打开命令面板，运行 **凭记忆复述（本节）**。

这一节下面出现一个回忆块，里面有一个问题。

## 凭记忆回答

1. 开始写你的答案。

笔记的其他部分会变模糊，这样你只能凭记忆回答。要取消模糊，按 Esc 或选择 **已模糊**。要再次模糊笔记，选择 **模糊笔记**。

2. 要提交，按 <kbd>⌘</kbd> <kbd>↵</kbd>（Windows 和 Linux 上按 <kbd>Ctrl</kbd> <kbd>↵</kbd>）。

Agent 在你的答案下面写反馈，然后就缺少或不对的地方追问一个问题。

3. 回答每个追问。

Agent 没有更多问题时，会写一段总结。

## 保留你的解释

1. 选择 **整理成文**。
2. 写下你现在认可的解释。输入框里预先填好了你的第一次回答。
3. 提交。

插件用你的解释替换这个块，并在下面加一个 `feedback` callout。callout 标题中有日期和结果。

要原样保留第一次回答，选择 **保留我的第一次回答**。

:::note
模糊是一项设置：**设置 → ICAP Learning Agent → 笔记中 → 回忆时模糊笔记**。
:::
