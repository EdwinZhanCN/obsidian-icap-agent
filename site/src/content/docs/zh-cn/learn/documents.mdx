Agent 可以读库中的 PDF、EPUB 和 Word（DOCX）文件。它像人读书一样读资料：先看目录，再只读需要的章节。用到 PDF 的某一页时，它给出指向那一页的链接。

## 就一份资料提问

1. 打开一个请求块：运行 **在这里向 Agent 提问**。
2. 输入 `@` 或 `[[`，再输入文件名的一部分。
3. 在列表中选择这份资料。
4. 写完请求的其余部分，然后选择 **发送**。

不链接资料也可以。Agent 也能自己找到资料。链接告诉它你指的是哪一份。

Agent 解释段落、向你提问或写笔记时，也可以用你的资料。

## Agent 怎样读资料

Agent 有两个用于资料的工具：

- `documents` 列出 Agent 可以读的资料和它们的章节。它还能在 Agent 读过的资料中，找到包含某些词的页或节。
- `read_document` 显示一份资料的结构：各个部分及其页码或节号。然后它读一个部分，或一段页码范围。

资料的结构来自它的书签、EPUB 的目录或 Word 文件的标题样式。如果 PDF 没有书签，插件根据文字的大小和粗细找出标题。这一步不用模型，所以没有花费。

## 打开引用的页

Agent 用链接引用 PDF 的某一页，例如 `[[机翼.pdf#page=41]]`。选择这个链接，就在那一页打开 PDF。保留请求的记录时，这些链接留在笔记中。

## 准备资料

Agent 第一次读一份资料时，插件先准备它。大文件可能需要一点时间。插件把结果存在它自己的文件夹 `.obsidian/plugins/icap-agent/docs/` 里，所以每份资料只读一次。你的库里不会多出文件夹。

**设置 → ICAP Learning Agent → 资料** 中有两项设置会改变这一点：

- **提前准备资料**：在这台设备上，在后台准备库中所有的 PDF、EPUB 和 Word 文件。
- **章节摘要**：让模型为每个部分写一行摘要。这大约消耗与资料字数相当的输入 token。默认关闭。

每台设备准备自己的资料。Obsidian Sync 不同步这个隐藏文件夹。

## 库外的资料

这一节只适用于桌面端。

- 使用 **你的 Pi 配置 + ICAP** 时，Agent 用你自己的 Pi 工具，可以读库外的文件。
- 使用 **仅 ICAP（隔离）** 时，Agent 只读这个库和你允许的文件夹。把每个文件夹的完整路径加到 **库外的文件夹** 中（**设置 → ICAP Learning Agent → 高级**），每行一个。

要就允许的文件夹中的一份资料提问，在请求中写出它的完整路径。`documents` 工具也会列出这些文件夹中的资料。

在手机上，Agent 只读库中的资料。

:::caution
Agent 读不了没有文字层的扫描版 PDF。插件不做文字识别（OCR）。
:::
