如果你打开 **把任务记录成笔记**（**设置 → 文件**），插件把每个任务记成一篇笔记，放在 `ICAP/Tasks/` 中。`ICAP/Activity.base` 显示这些任务笔记。下面是这个 base 的第一个视图，它和插件用的是同一个组件。

这一项默认关闭。关闭时插件不往你的库里写任何内容，状态栏中的标记打开插件自己的最近任务列表。

## 插件什么时候记录任务

请求块出现下面任一情况时，插件把它记成任务：

- Agent 用了工具。
- Agent 新建、修改或删除了文件。
- Agent 问了你问题。
- 对话超过一轮。

做笔记的任务，插件每次都记录。解释、回忆、检查和测验，插件不记录。

## 回到提问的位置

选择任务的名称，打开你提问的那篇笔记。笔记在请求块处打开。如果你保留了这个块，笔记在 `[!request]` 记录处打开。要打开任务笔记，选择名称时按住 **Ctrl**（macOS 上是 **Cmd**）。

## 怎么读一行

- **圆点**显示状态。实心并闪动：Agent 在工作。空心圈：Agent 在等你。灰色：完成。红色：失败。
- **标题下面一行**显示模型、任务的笔记、改动的文件、用时和估算的花费。
- **步骤条**从左到右显示任务的步骤。浅色是读取的步骤。实色是改动文件的步骤。斜纹是等你的步骤。

要看一个步骤做了什么，把指针移到它上面，或把焦点移到它上面。

步骤条只显示在本设备上运行的任务。

## ICAP 样式

要用你主题的强调色，关闭 **ICAP 样式**。上面示例右上角的复选框也是这个开关。
