引导笔记 **用 ICAP 学习** 是一篇关于 ICAP 框架的短文。读它的时候，你会把插件的每种交互都用一遍。读完后，它就是你的第一篇学习笔记。

如果引导笔记没有打开，打开命令面板，运行 **打开指南**。如果你删除了这篇笔记，这个命令会重新创建它。

## 1. 获取解释

1. 在「四种投入方式」一节中，双击 *scaffolding* 这个词。
2. 在选区旁，选择 **解释**。

解释显示在这一段的下面，页边有一条笔迹线。

3. 要改变解释，选择 **更深入**、**举个例子** 或 **说浅一点**。
4. 二选一：
   - 要保留解释，选择 **留在笔记里**。插件把它作为 callout 写进笔记。
   - 要去掉它，选择 **丢弃**。笔记不会改变。

## 2. 回答一个问题

1. 在提问块中选择一个答案。
2. 选择 **提交**。

Agent 针对你的答案回复。如果答案错了，Agent 不直接给出正确答案，而是问你一个能帮你找到答案的问题。

## 3. 凭记忆解释

1. 在回忆块中开始写你的答案。

笔记的其他部分会变模糊，这样你只能凭记忆回答。要取消模糊，按 Esc。

2. 提交你的答案。

Agent 告诉你缺了什么、错在哪里，并追问一个问题。它不替你写答案。

3. 结束时，选择 **整理成文**。你最终的答案和反馈都留在笔记中。

## 4. 让 Agent 写一篇笔记

1. 在「为 ICAP 框架写一篇独立的概念笔记」这个块中，选择 **开始**。

Agent 在你的库中写一篇概念笔记。它还提出对引导笔记的一处修改：加一个指向新笔记的链接。块中以差异对比显示这处修改。

2. 读一遍差异对比。要写入修改，选择 **应用修改**。

Agent 工作时，状态栏右侧会出现一个圆点。要查看活动，选择这个圆点。

## 5. 让 Agent 做任何事

1. 把光标放在一个空行上。
2. 打开命令面板，运行 **在这里向 Agent 提问**。
3. 输入请求，然后按 <kbd>⌘</kbd> <kbd>↵</kbd>（Windows 和 Linux 上按 <kbd>Ctrl</kbd> <kbd>↵</kbd>）。

在请求中：

- 输入 `[[` 或 `@` 添加文件链接。Agent 会使用你链接的文件。
- 在开头输入 `/` 使用命令，例如 `/model` 只在这个块中换一个模型。

4. 结束时，选择 **保留记录**。对话会变成笔记中的普通 Markdown。

## 下一步

- 逐个学习每种交互：从[获取解释](/zh-cn/learn/explain/)开始。
- 告诉 Agent 关于你和你的库的情况：**设置 → ICAP Learning Agent → 关于你**。
