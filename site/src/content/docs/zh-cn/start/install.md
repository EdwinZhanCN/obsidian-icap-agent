1. 在 Obsidian 中打开 **设置 → 第三方插件**。
2. 如果安全模式是开着的，先关闭安全模式。
3. 选择 **浏览**。
4. 搜索 **ICAP Learning Agent**。
5. 选择 **安装**，然后选择 **启用**。

插件会打开一篇引导笔记 **用 ICAP 学习**。让它保持打开，[第一课](/zh-cn/start/first-lesson/)要用到它。

## 手动安装

只有无法使用第三方插件浏览器时，才用这个方法。

1. 从最新的 [release](https://github.com/EdwinZhanCN/obsidian-icap-agent/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 把这三个文件放进 `<你的库>/.obsidian/plugins/icap-agent/`。
3. 在 Obsidian 中打开 **设置 → 第三方插件**，然后启用 **ICAP Learning Agent**。

## 如果你用过 ICPA

ICPA（`icpa-agent`）是这个插件以前的名字。ICAP 第一次启动时会复制 ICPA 的设置。之后，移除 ICPA。

下一步：[接上模型](/zh-cn/start/connect-a-model/)。
