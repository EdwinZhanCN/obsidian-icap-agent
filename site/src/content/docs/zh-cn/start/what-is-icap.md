ICAP Learning Agent 是一个 Obsidian 插件。它把一个 Agent 放进你阅读的笔记中。Agent 给你解释，向你提问，对你的回答给出反馈，并完成你交给它的工作。插件没有聊天面板。

## 四种学习方式

名字来自 ICAP 框架（Chi & Wylie, 2014）。这个框架把学习者对待文本的方式分成四种：

| 方式 | 你做什么 |
|---|---|
| **P**assive 被动 | 你阅读。 |
| **A**ctive 主动 | 你选择、标记或重新整理文本。 |
| **C**onstructive 建构 | 你产出文本中没有的东西：用自己的话解释、举例、对比。 |
| **I**nteractive 互动 | 你和一个伙伴一起推理。每一方都在对方的话上继续。 |

从被动到互动，理解通常越来越深。插件让每一步向深处走都很容易，但不强迫你走。

## 插件做什么

- **解释。** 选中一个词或一段文字，解释显示在它下面。
- **回忆。** 凭记忆解释一节内容，Agent 针对你写的内容回应。
- **检查。** 回答关于一节或一篇笔记的问题，得到反馈。
- **请 Agent 做事。** 在笔记中放一个请求块，告诉 Agent 要做什么。
- **读资料。** Agent 读你库中的 PDF、EPUB 和 Word 文件。
- **活动。** 插件把每个任务记成一篇笔记，记下状态和花费。

## 什么会留在笔记中

在你保留之前，Agent 的文字都是临时的。你保留时，插件把普通的 Markdown 写进笔记。没有插件，你的笔记照样能读。

没有你的同意，Agent 不改笔记。它把对已有笔记的每处修改显示成差异对比。只有你应用修改，插件才写入。

## 你需要什么

- Obsidian 1.11.4 或更高版本，电脑、iPhone、iPad 或 Android 设备都可以。
- 一个模型服务商的账号，或在你电脑上运行的模型。服务商直接向你收费。ICAP 没有账号，也没有服务器。
