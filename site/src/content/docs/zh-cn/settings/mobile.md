手机或平板上的 Obsidian 没有 Node，而 Pi 需要 Node。在手机上，ICAP 使用自己的 Agent。这个 Agent 和电脑上用相同的模型库、相同的教学规则和相同的 ICAP 工具。添加第一个 Key，请看[接上模型](/zh-cn/start/connect-a-model/)。

## 手机上的设置

手机上的 **设置 → ICAP Learning Agent** 显示这些组：

| 组 | 设置 |
|---|---|
| （无标题） | **Agent**、**模型服务商**、**模型**、**思考强度** |
| **API Key** | 每个服务商一个 Key |
| **自定义端点** | 你的端点，以及 **添加端点** |
| **关于你** | 和电脑上相同 |
| **笔记中** | 和电脑上相同 |
| **文件** | 和电脑上相同 |
| **资料** | 和电脑上相同 |
| **高级** | 只有 **并行任务** |

手机上不显示 **登录…**、**自定义端点…**、**Agent 配置**、**库外的文件夹** 和 **记住请求的上下文**。

## API Key

**API Key** 一组中，每个服务商一行：Anthropic、OpenAI、Google Gemini、OpenRouter、DeepSeek、Mistral、Groq 和 xAI。

1. 找到你的服务商。
2. 如果你没有 Key，选择 **获取 Key**。服务商的页面会打开。
3. 在这一行的输入框中添加 Key。

名称旁的对勾表示 Key 已设置。

Key 存在这台设备上 Obsidian 的钥匙串中。它不在库中，也不在插件数据中，不会同步。每台设备都要添加一次。Key 在钥匙串中的默认名称是 `icap-<服务商>`，例如 `icap-anthropic`。

## 自定义端点

局域网中的 Ollama 或 LM Studio、中转站，或其他兼容 OpenAI 或 Anthropic 的 API，用自定义端点接入。

1. 在 **添加端点** 中，选择 **添加…**。
2. 在 **名称** 中，输入名称。
3. 在 **Base URL** 中，输入到版本号为止的 URL，例如 `http://192.168.1.20:11434/v1`。
4. 在 **API** 中，选择 **OpenAI Chat Completions**、**OpenAI Responses** 或 **Anthropic Messages**。
5. 在 **模型** 中，输入模型 ID。两个 ID 之间用逗号或换行分隔。
6. 如果服务器需要 Key，保持 **需要 API Key** 打开。如果不需要，关闭它。
7. 选择 **保存**。

如果端点需要 Key，它下方显示一行「端点名称 + 的 Key」。在这一行添加 Key。要修改端点，选择 **编辑**。要删除端点，选择 **移除**。

保存时，ICAP 检查一次服务器是否允许应用以流式接收回复。

- 如果允许，模型写回复时，回复逐步显示。
- 如果不允许，回复通过 Obsidian 一次性到达。你会看到「等待完整回复…」。

:::caution
回复一次性到达时，停止按钮显示为 **停止等待——这次请求仍会计费**。它只停止等待。服务器仍会完成请求，服务商仍会收费。
:::

## 模型

手机上的模型和电脑上的模型是两个独立的设置。**默认** 是第一个有 Key 的服务商的默认模型。请看[模型和服务商](/zh-cn/settings/models/)。

## 和电脑上的不同

- **只有一种 Agent 配置。** Agent 总是像 **仅 ICAP（隔离）** 一样工作，只有 ICAP 的工具。它没有文件工具，也没有 shell。你的 Pi 技能、扩展和 MCP 服务器都不能用。
- **只能用 API Key 和自定义端点。** 你不能用订阅账号登录，也不能用 Bedrock 或 Vertex。
- **不能读库外的文件夹。** Agent 只读库。
- **没有会话缓存。** 请求块的每一轮都把完整的对话再发给模型一次。这会用更多输入 token。
- **没有 `/compact`。** 在请求块中，只能用 `/model` 和 `/thinking`。

:::note
如果 iOS 在回复到达时停止了 Obsidian，任务会暂停。再次打开这篇笔记，选择 **继续**。
:::
