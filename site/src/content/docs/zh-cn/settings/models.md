**设置 → ICAP Learning Agent** 的第一组设置没有标题。它决定 Agent 用哪个模型，以及 Agent 怎样连接这个模型。第一次登录，请看[接上模型](/zh-cn/start/connect-a-model/)。

## 设置项

| 设置 | 作用 | 默认值 | 平台 |
|---|---|---|---|
| **Pi**（电脑）或 **Agent**（手机） | 显示 Agent 的版本和可用模型的数量。 | — | 两者 |
| **模型服务商** | 电脑上：**登录…** 和 **自定义端点…**。手机上：只有一段说明。 | — | 两者 |
| **模型** | 任务没有自己的模型时，使用这个模型。 | **Pi 默认**（电脑），**默认**（手机） | 两者 |
| **思考强度** | 模型回复前思考多少：`off`、`minimal`、`low`、`medium` 或 `high`。 | `low` | 两者 |
| **API Key** | 每个服务商一个 Key。 | 空 | 手机 |
| **自定义端点** | ICAP 没有列出的服务器。 | 无 | 手机 |

## Pi 或 Agent

这一行显示 Agent 的版本，然后显示你能用的模型数量。插件获取模型列表时不发送提示词，所以检查不花钱。

如果这一行显示「还没有模型配置了凭证」（电脑）或「还没有可用的模型」（手机），请让 Agent 能用一个服务商。然后，选择这一行末尾的 ↻（**重新检查**）。

## 模型服务商

在电脑上，Agent 是 Pi，凭据由 Pi 保存。

- **登录…** 打开 **登录模型服务商**。选择服务商，然后选择 **账号登录**，或输入 API Key。Pi 把凭据写入 `~/.pi/agent/auth.json`。
- **自定义端点…** 打开 **自定义模型端点**。Ollama、LM Studio、vLLM、中转站或其他兼容 OpenAI 的 API，用它接入。Pi 把端点写入 `~/.pi/agent/models.json`。

服务商就绪后，**模型服务商** 的说明以「已就绪：」开头，后面是服务商的名称。

在手机上，Key 和端点在下方各有一组：**API Key** 和 **自定义端点**。请看[在手机上](/zh-cn/settings/mobile/)。

## 模型

列表只显示有凭据的模型。

- 在电脑上，**Pi 默认** 跟随你 Pi 设置中的模型。括号中是这个模型现在的名称。
- 在手机上，**默认** 是第一个有 Key 的服务商的默认模型。

手机上的模型和电脑上的模型是两个独立的设置。每台设备有自己的 Key，所以每台设备选择自己的模型。

## 思考强度

级别越高，回复越慢，用的 token 越多。解释通常用 `low` 就够。

## 为一个请求块设置模型

请求块可以用和设置中不同的模型。在块中把命令作为请求输入：

| 命令 | 作用 |
|---|---|
| `/model` | 显示这个块的模型。 |
| `/model <名称>` | 从下一个请求起，这个块用 `<名称>`。 |
| `/model default` | 恢复为设置中的模型。 |
| `/thinking` | 显示这个块的思考强度和可选的级别。 |
| `/thinking <级别>` | 这个块用 `<级别>`：`off`、`minimal`、`low`、`medium`、`high` 或 `xhigh`。 |
| `/thinking default` | 恢复为设置中的思考强度。 |

这些命令只改变这个块。Agent 看不到它们，它们也不进入保留的记录。命令只在请求块中有效。在回忆、检查或测验中，开头的 `/` 只是文字。

如果模型名称不在有凭据的模型列表中，块会显示一条警告。下一个请求可能会失败。

## 每个任务的模型

每篇任务笔记在属性 `icap-model` 中记录最近一次运行的模型，例如 `anthropic/claude-sonnet-4-5`。设置中的模型只是默认值，只用于还没有模型的任务。
