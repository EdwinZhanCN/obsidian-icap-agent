**设置 → ICAP Learning Agent** 中的 **关于你** 一组，向 Agent 介绍你和这个库。Agent 每次任务都用它。

| 设置 | 作用 | 默认值 | 平台 |
|---|---|---|---|
| **你的背景** | 你已经知道的东西。 | 空 | 两者 |
| **你喜欢怎样学** | 每次任务的语言、风格和深浅。 | 空 | 两者 |
| **这个库的约定** | 在库的根目录创建 `AGENTS.md`，或打开它。 | 无文件 | 两者 |

## 你的背景

用几行短句写下你已经知道的东西。例如：「熟悉 Python；刚开始学 C++；会基础线性代数。」

Agent 的解释只基于两样东西：你在这里写的内容，和你笔记中的内容。如果这一项为空，Agent 不猜你的水平。它可以读库中相关的笔记。

## 你喜欢怎样学

写下你想要的语言、风格和深浅。例如：「用中文解释，术语保留英文，多用小段代码举例。」

Agent 每次任务都遵循这段文字。

## 这个库的约定

这一项在库的根目录写一篇笔记 `AGENTS.md`。这篇笔记告诉 Agent 你在这个库中学什么、笔记怎样组织。两种 Agent 配置下，Agent 每次任务前都读它。你随时可以修改这篇笔记。

如果 `AGENTS.md` 不存在，按钮是 **设置…**。如果它存在，按钮是 **打开**。

### 创建 AGENTS.md

1. 选择 **设置…**。
2. 选择学习的类型：
   - **课程**：上课、讲义、作业、考试。
   - **读书**：一本或几本书，按章读。
   - **研究 / 论文**：读论文、做文献综述。
   - **语言**：词汇、语法、阅读。
   - **编程 / 技术**：语言、框架、系统。
   - **从空白开始**：你自己写规则。
3. 在 **你在这里学什么？** 中，输入一两句话。
4. 可选：在 **学习资料放在哪？** 中，选择放书、讲义或论文的文件夹。
5. 可选：在 **有没有 Agent 不能改动的文件夹？** 中，选择一个文件夹。Agent 仍然可以读它。
6. 选择 **预览**。
7. 阅读文字，需要时修改。
8. 选择 **创建 AGENTS.md**。

插件创建这篇笔记并打开它。从下一个任务起，Agent 读它。

每种学习类型加入自己的规则。例如，**课程** 让 Agent 先给提示，再给完整解答。所有类型还加入几条通用规则：

- 新建笔记前，先找同一主题的笔记。
- 只链接已有的笔记，或同一个任务中新建的笔记。
- 不编造出处、引文或数据。

:::note
向导从不覆盖文件。如果 `AGENTS.md` 已经存在，插件不改动它。
:::

### Agent 读哪些 AGENTS.md

Agent 读库内的 `AGENTS.md` 文件。选择 **你的 Pi 配置 + ICAP** 时，它还读 Pi 的全局文件 `~/.pi/agent/AGENTS.md`。它从不读库的上级文件夹中的 `AGENTS.md`，因为那个文件是为其他工作写的。请看[Agent 配置](/zh-cn/settings/agent/)。
