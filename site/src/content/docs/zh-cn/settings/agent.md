**设置 → ICAP Learning Agent** 中的 **高级** 一组，决定 Agent 能用什么、怎样运行。

| 设置 | 作用 | 默认值 | 平台 |
|---|---|---|---|
| **Agent 配置** | Agent 能用哪些工具和文件。 | **你的 Pi 配置 + ICAP** | 电脑 |
| **库外的文件夹** | Agent 可以读的库外文件夹。 | 无 | 电脑，只在 **仅 ICAP（隔离）** 时 |
| **记住请求的上下文** | 追问时继续 Agent 的会话。 | 打开 | 电脑 |
| **并行任务** | 最多同时运行的任务数，1 到 6。 | 3 | 两者 |

## Agent 配置

在电脑上，Agent 是 [Pi](https://pi.dev)。Pi 是一个通用的 Agent。你也可以在命令行中用它，带上你自己的技能和扩展。**Agent 配置** 决定 ICAP 是否使用这套配置。

| | **你的 Pi 配置 + ICAP** | **仅 ICAP（隔离）** |
|---|---|---|
| 模型和凭据 | Pi 的（`~/.pi/agent/`） | Pi 的（`~/.pi/agent/`） |
| ICAP 的工具 | 有 | 有 |
| 读库中的文件 | 能 | 能 |
| 直接修改文件 | 能 | 不能 |
| Shell 命令 | 能 | 不能 |
| 你的技能、扩展、提示词模板和 MCP 服务器 | 有 | 没有 |
| Pi 的全局文件 `~/.pi/agent/AGENTS.md` | 读 | 不读 |
| 库内的 `AGENTS.md` 文件 | 读 | 读 |
| 库的 `.pi/` 文件夹 | 库受信任时加载 | 不加载 |
| 库外的文件夹 | 通过 Pi 的 shell | 只有你允许的文件夹 |

### 你的 Pi 配置 + ICAP

这是默认选项。Agent 有你全部的 Pi 配置，ICAP 再加上自己的工具和教学规则。这和你自己在库中运行 Pi 一样。

Agent 可以直接修改文件，不需要你应用一个修改提议。ICAP 不阻止这些修改。它把每个修改记录在做出修改的任务上。你在[活动](/zh-cn/learn/activity/)中看到这些修改。

:::caution
在这种配置下，库中的文字可能影响 Agent，Agent 也可以修改文件。你的扩展和 MCP 服务器还可能连接它们自己的服务。如果你不想这样，请选择 **仅 ICAP（隔离）**。
:::

### 仅 ICAP（隔离）

Agent 只有 ICAP 的工具和 Pi 的只读工具。它可以新建笔记，但不能直接修改已有的笔记。要修改已有的笔记，它提出一个修改，由你决定是否应用。它只能读库和 **库外的文件夹** 中列出的文件夹。

如果你希望 Agent 每次的行为都一样，或者你自己不用 Pi，请用这个配置。

### 项目信任

库可以有自己的 Pi 文件夹 `.pi/`，其中有扩展、技能和设置。其中一些文件，Pi 只从受信任的项目中加载。

ICAP 不询问你是否信任。它使用你在 Pi 命令行中做的决定。如果你没有做过决定，只有当库的 `.pi/` 中没有需要信任的内容时，ICAP 才加载它。选择 **仅 ICAP（隔离）** 时，ICAP 从不加载它。

## 库外的文件夹

这一项只在 **Agent 配置** 为 **仅 ICAP（隔离）** 时显示。使用你的 Pi 配置时，适用 Pi 自己的权限。

每行输入一个绝对路径，例如 `/Users/me/Books`。路径以 `/`、`~` 或盘符（例如 `C:\`）开头。插件忽略其他行。

之后，Agent 可以读这些文件夹中的文件和资料。它不能修改它们。

## 记住请求的上下文

一个请求块可以有多轮对话。打开这一项后，追问时 Agent 从上一条回复继续它的会话。Agent 不再重新读完整的对话。

对话的记录始终是笔记。如果你修改了块中的轮次，会话就和块不再一致。这时 Agent 从块中的文字重新开始。如果关闭这一项，每次追问都从块中的文字重新开始。

保留或清除这个块时，插件删除这个会话。

## 并行任务

这是同时运行的任务的最大数量。超过这个数量的任务，等到有任务结束后再运行。
