ICAP 只把你的请求发给你选择的模型服务商。ICAP 没有服务器、没有账号、没有遥测，也没有统计分析。它不上传你的库。

## 请求发到哪里

每个任务把请求发给这个任务的模型。服务商是你在 **模型服务商** 中设置的那一个：你登录的服务商、API Key 所属的服务商，或自定义端点。服务商直接向你计费。

除了以下情况，ICAP 本身不发出其他网络请求：

| 请求 | 什么时候 | 发到哪里 |
|---|---|---|
| 登录 | 你在电脑上选择 **登录…**。 | 服务商的登录页面。 |
| 端点检查 | 你在手机或平板上保存一个端点。 | 你输入的端点。ICAP 检查一次服务器是否允许应用以流式接收回复。 |
| **获取 Key** | 你在手机或平板上选择它。 | 服务商的 Key 页面，在你的浏览器中打开。 |

:::caution
在电脑上，如果 Agent 配置是 **你的 Pi 配置 + ICAP**，Agent 会使用你自己的 Pi 扩展、MCP 服务器和 shell。它们可以连接自己的服务，ICAP 不控制它们。要避免这种情况，在 **Agent 配置** 中选择 **仅 ICAP（隔离）**。
:::

交互式图示不能联网。图示不能从网上加载脚本、字体或图片。它只能打开库中的链接，并且只在你使用了这个图示之后。

## 任务发送什么

任务发送你正在用的笔记的上下文。ICAP 从笔记中收集这些上下文：

- 笔记的名字和路径，
- 光标上方的各级标题，
- 笔记属性，
- 这篇笔记链接到的笔记的名字（最多 30 个），
- 光标或选中内容周围的段落，
- 光标所在的小节，
- 光标周围约 9000 个字符的笔记内容，
- 选中的文字（如果有）。

每种任务只用其中一部分。例如，解释发送这段话、它周围的笔记内容和选中的文字。

任务还发送：

- 设置中 **你的背景** 和 **你喜欢怎样学** 的文字，
- 库中的 `AGENTS.md`（如果有），
- 对请求块，块中的对话，即笔记中显示的内容，
- 对回忆、检查或测验，你的回答。

在电脑上，如果 Agent 配置是 **你的 Pi 配置 + ICAP**，Agent 还会得到 Pi 的全局 `AGENTS.md`。ICAP 从不加载库上层文件夹中的 `AGENTS.md`。

### Agent 读取什么

Agent 可以用工具读取库中更多的内容：搜索、链接、反向链接、笔记和资料。它读到的内容会发给服务商。在 **仅 ICAP（隔离）** 模式下，Agent 只能读取库和 **库外的文件夹** 中列出的文件夹。在手机或平板上，Agent 只能读取库。

打开 **章节摘要** 时，模型把每份资料读一次，写出摘要。这会把库中资料的文字发给服务商。

## 你的 Key 存在哪里

| 设备 | Key 存在哪里 |
|---|---|
| 电脑 | Pi 的文件 `~/.pi/agent/auth.json`，或 shell 配置文件中的环境变量。自定义端点在 `~/.pi/agent/models.json`。ICAP 不另存副本。 |
| 手机或平板 | 这台设备上 Obsidian 的密钥存储。Key 不在库中，也不同步。 |

:::caution
`models.json` 中的 Key 是明文。要让 Key 不写进文件，在 Key 的位置输入 `$NAME`。Pi 会读取环境变量 `NAME`。
:::

在电脑上，ICAP 第一次启动 Agent 时运行一次你的登录 shell。它读取 Obsidian 没有的环境变量，例如 `~/.zshrc` 中的服务商 Key。它不替换 Obsidian 已有的变量。

## 什么留在库中

| 内容 | 位置 |
|---|---|
| 设置和进行中的块的状态 | `.obsidian/plugins/icap-agent/data.json` |
| 请求块保存的会话（仅电脑） | `.obsidian/plugins/icap-agent/sessions/` |
| 资料缓存 | `.obsidian/plugins/icap-agent/docs/` |
| 任务笔记和 Activity base（只在 **把任务记录成笔记** 打开时） | `ICAP/` |

如果你同步库，这些文件会一起同步。手机或平板上的 Key 不同步。
