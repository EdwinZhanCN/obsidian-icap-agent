要运行命令，打开命令面板，输入命令名。ICAP 没有默认快捷键。要给命令设快捷键，打开 **设置 → 快捷键**，搜索“ICAP”。

## 编辑器命令

编辑器命令只在编辑器中打开笔记时可用（实时预览或源码模式），在阅读视图中不可用。

每个编辑器命令都有图标。在手机或平板上，在 Obsidian 的设置中把这些命令加到移动端工具栏。

| 命令 | 作用 | 图标 |
|---|---|---|
| **在这里向 Agent 提问** | 在光标下方加一个请求块。如果选中了文字，Agent 把选中内容作为上下文。 | `message-circle-question` |
| **在上下文中解释选中内容** | 在段落旁显示选中文字的解释。 | `lightbulb` |
| **凭记忆复述（本节）** | 为光标所在的一节加一个回忆块。 | `brain` |
| **检查我写的内容（选中内容或段落）** | 为选中的文字或光标所在的段落加一个检查块。 | `spell-check` |
| **检验我对本节的理解** | 为光标所在的一节加一个测验块。 | `list-checks` |
| **检验我对整篇笔记的理解** | 为整篇笔记加一个测验块。 | `clipboard-check` |
| **用选中内容新建概念笔记** | 开始一个任务，为选中的概念写一篇新笔记。如果没有选中内容，ICAP 显示“请先选中一个概念。” | `file-plus-2` |
| **把本笔记的关键概念整理成笔记** | 开始一个任务，为这篇笔记的每个关键概念写一篇笔记。 | `files` |
| **写一篇对比笔记…** | 打开 **对比概念** 对话框。在 **这个** 和 **和** 中输入两个概念，然后选择 **写对比笔记**。如果选中了文字，它是第一个概念。 | `columns-2` |
| **进入最近的解释或问题** | 把焦点移到光标处或光标下方的第一个解释或块。如果笔记中没有，ICAP 显示“这篇笔记里还没有解释或问题。” | `corner-down-right` |

## 其他命令

这些命令在任何视图中都可用。

| 命令 | 作用 | 图标 |
|---|---|---|
| **显示活动** | 打开 `ICAP/Activity.base`。如果有任务在等你回答且没有任务笔记，就显示这个任务。如果 Bases 核心插件已关闭，就打开活动列表。 | `activity` |
| **从最近的活动重建任务笔记** | 为最近 60 个任务重新写入缺失的任务笔记。误删任务笔记后用它。 | `list-restart` |
| **打开指南** | 打开指南笔记。如果你删除了它，ICAP 重新创建。 | `book-open` |
| **这个库的约定（AGENTS.md）** | 打开库根目录中的 `AGENTS.md`。如果没有，就打开写这个文件的对话框。 | `scroll-text` |

## 编辑器菜单

在笔记中右键，打开编辑器菜单。

以下菜单项只在选中文字时显示：

| 菜单项 | 等同于 | 图标 |
|---|---|---|
| **在上下文中解释** | **在上下文中解释选中内容** | `book-open` |
| **检查我写的内容** | **检查我写的内容（选中内容或段落）** | `pen-line` |
| **新建概念笔记** | **用选中内容新建概念笔记** | `file-plus` |

以下菜单项总是显示：

| 菜单项 | 等同于 | 图标 |
|---|---|---|
| **在这里向 Agent 提问** | **在这里向 Agent 提问** | `message-square-text` |
| **凭记忆复述** | **凭记忆复述（本节）** | `brain` |
| **检验我的理解** | **检验我对本节的理解** | `list-checks` |

## 状态栏和功能区

- **在电脑上**，ICAP 在状态栏中加一个标记。它的提示文字是 **学习活动**。标记显示任务的状态，例如“进行中”或“2 个问题等你回答”。选择它，作用和 **显示活动** 相同。
- **在手机或平板上**，Obsidian 没有状态栏。ICAP 在功能区加一个按钮 **显示活动**，图标是 `activity`。

## 在块中

在块中，按 <kbd>Mod</kbd>+<kbd>Enter</kbd> 提交或发送。<kbd>Mod</kbd> 在 macOS 上是 <kbd>Cmd</kbd>，在其他系统上是 <kbd>Ctrl</kbd>。每个块也为每个操作显示一个按钮，供触屏使用。
